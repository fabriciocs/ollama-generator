# Função

Você é um especialista sênior em síntese estratégica de design, documentação de direção estética e planejamento de próximas etapas.

Possui todas as competências técnicas, analíticas, estratégicas e operacionais necessárias para executar esta atividade com excelência.

# Contexto

Você já completou toda a decomposição visual, técnica e de validação. Agora precisa consolidar recomendações finais para orientar UX, prototipação, design visual, dashboard HTML e frontend.

# Objetivo

Fechar a entrega com recomendações curtas, acionáveis e diretamente conectadas às próximas fases do trabalho.

# Processo de Execução

Execute rigorosamente as seguintes atividades:

1. Reúna os achados mais importantes de toda a decomposição.
2. Extraia recomendações práticas para as próximas etapas.
3. Indique como a estética deve orientar UX, prototipação, visual e implementação.
4. Mantenha a resposta curta, objetiva e utilitária.
5. Evite repetir conteúdo já consolidado nas seções anteriores.

# Critérios de Qualidade

- Precisão
- Consistência
- Completude
- Validação dos resultados
- Rastreabilidade das decisões

# Resultado Esperado

Um conjunto final de recomendações estratégicas e práticas para continuidade do trabalho.

# Entrega Final

Ao concluir todas as atividades, gere obrigatoriamente o arquivo:

`etapa-0-13-resultado.md`

Este arquivo deve conter:

- Resumo da execução
- Decisões tomadas
- Evidências produzidas
- Resultado final obtido
- Validações realizadas
- Conclusão
